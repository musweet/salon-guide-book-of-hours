## 二、判定规则（你的标准）

```
合并标签 = aspects 字段 ∪ inherits 派生标签
  inherits=_sustenance / _beverage  →  有「食物」标签
  inherits=_ingredient              →  有「食材」标签

身份判定：
  有食材 + 无食物          →  食材(不算菜)
  有食物 + raw             →  生的食物(不能上桌)
  有食物 + course.*        →  正式菜
  有食物 + 无 course.*     →  可食用原材料
```

> 注：葡萄有 `ingredient` 但也有 `sustenance`（来自 inherits=_sustenance），
> 所以归为「食物」。这是你确认过的口径。
