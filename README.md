# 司辰之书 · 沙龙点菜助手

一个为游戏《司辰之书》（Book of Hours）制作的**离线单文件沙龙点菜助手**，帮助你在一场沙龙前规划：选什么宴会、邀谁、备多少料、上几道菜、配几杯饮品，并预估能拿到多少教诲。

## 这是什么

- **单文件网页**：把数据、样式、逻辑、272 张卡牌配图全部内嵌在 `index.html` 里，双击即可在浏览器打开，无需联网、无需安装、无需注册。
- **数据全部来自维基**：宴会类型、访客偏好、菜谱、合成树、订货目录、教诲矩阵均取自 [boh.huijiwiki.com](https://boh.huijiwiki.com/) 的 wikitext，不编造。
- **支持导入/导出配置**：可以把当前配置导出为 JSON，方便存档或发给别人复现同一场沙龙。

## 功能一览

### ① 选宴会
5 种宴会（野餐 / 午前茶 / 午宴 / 下午茶 / 晚宴），维基原文。午前茶 / 下午茶禁烈酒，会实时提示是否违规。

### ② 选访客
28 位访客（含 3 位村民）。显示偏好性相、忌口、忌饮、备注。N 位访客需 N 道菜 + N 杯饮品；一份食物或饮品可同时满足多名访客的性相。

### ③ 订货与库存登记
按来源分组：采集 / 村民 / 订货 / 自制 / 饮品。每项 `+` 登记库存、`−` 减少库存。来源仅作说明，不限制加减。

### ④ 仓库
显示所有已登记物品及备餐池余量。工具（厨房用碗、刀）不消耗，只分「可用/不可用」。

### ⑤ 餐桌
两竖列（菜 | 饮）。实时显示：
- 访客性相需求（食物 / 饮品独立检查）
- 数量汇总（菜 X/N · 饮 X/N）
- 宴会规则提示（晚宴禁烈酒）
- 性相全部满足时显示 ✓

### ⑥ 菜谱
78 道菜，支持筛选：
- 按满足度排序 / 符合访客性相 / 可制作 / 可食用素材（采集品生吃）
- 按性相筛选（心 / 蜜 / 鳞 / 铸 / 月 / 穹 / 杯 / 灯 / 刃 / 启 / 蛾 / 冬 / 引）
- 每道菜有「配方详情」按钮，展开看原料、工具、产物性相、合计备餐池需求。

### ⑦ 饮品上架
饮品按小杯计。大杯（壶）按 1 壶 = 2 杯、瓶 = 3 杯、半壶/近空 = 1 杯折算。

### ⑧ 教诲预估
选访客后自动计算：N 人 = N×(N−1)/2 组对谈。展示已标注的对谈与技艺。村民 + 访客办野餐是前期获取教诲的高效组合。

### ⑨ 速查表
性相 13 种、宴会 5 种、通用规则一览。

### ⑩ 规则说明
数据来源、工具不消耗、数量要求、村民、分装比例等维基规则。

## 操作流程

一场沙龙的标准流程：

1. **选宴会**（阶段 1）—— 决定场合和禁令。
2. **选访客**（阶段 2）—— N 人需 N 菜 + N 饮。
3. **订货备料**（阶段 3）—— 在「订货与库存登记」面板 `+` 原料；可导出配置存档。
4. **做菜上桌**（阶段 4）—— 在「菜谱」面板点「上桌」；有库存的中间产物（生面团等）会自动展开为底层原料。
5. **饮品上架**（阶段 5）—— 在「饮品上架」面板点「上桌」，按小杯计数。
6. **教诲预估**（阶段 6）—— 自动计算对谈组数和技艺。
7. **速查**（阶段 7）—— 查性相、宴会、通用规则。

### 中间产物与变体

- **生面团**有两种做法：面粉+黄油 或 面粉+奶。助手会自动挑选当前原料能完成的一种。
- **烤牛肉**产出副产物「口水油」；下架烤牛肉时副产物会收回，依赖它的菜（豪华烤土豆等）会被级联下架并返还原料。

### 导入 / 导出

- 在「订货与库存登记」面板底部点 **💾 导出配置**，保存为 JSON。
- 点 **📂 导入配置**，选择 JSON 文件即可恢复。

## 数据来源

- 主站：https://boh.huijiwiki.com/
- 关键页面：合成表、DLC、沙龙、访客列表、货币机制、订货单目录、物品合成整理
- 性相：维基原文 13 种
- 宴会：维基原文 5 种（野餐 / 午前茶 / 午宴 / 下午茶 / 晚宴）
- 分装比例：1 壶 = 2 杯（茶/水），1 瓶 = 3 杯（酒），半壶/近空 = 1 杯

## 离线使用

`index.html` 是完整的离线单文件，272 张卡牌配图以 base64 内嵌，总大小约 5.5 MB。下载到本地双击即可，无需任何后端。

## 技术细节

- 纯前端：HTML + CSS + JavaScript，无框架、无依赖、无构建。
- 数据：JSON 内嵌在 `<script id="data">` 里，渲染时解析。
- 测试：Node.js 跑 DOM 桩，240+ 自动化测试覆盖数据形状、宴会、访客、菜谱、变体、级联下架、订单/锁定移除等。
